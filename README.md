# House of the Dragon

Página estática que apresenta um carrossel com os dragões da série House of the Dragon (Casa Targaryen), com imagem de fundo e informações que trocam ao clicar nos botões de navegação.

## Tecnologias

- HTML5
- CSS3 (variáveis, `@keyframes`, `@font-face`, media queries)
- JavaScript puro (DOM)

## Como visualizar

Não há dependências para instalar nem servidor para rodar. Basta abrir o arquivo `index.html` diretamente no navegador.

## Estrutura

- `index.html` — página principal
- `src/css/` — estilos (`reset.css`, `estilos.css`, `responsivo.css`)
- `src/js/index.js` — lógica do carrossel de dragões
- `src/imagem/` — imagens dos dragões
- `src/fontes/` — fonte customizada (GOT.ttf)
